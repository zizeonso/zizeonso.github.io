# Photoreal Spacecraft Artwork

Original AI-generated transparent images, created with the built-in image_gen
tool. These are mission-inspired visualizations, not official photographs or
verified engineering models. Exact prompts are preserved in `generation.json`.

The original PNGs are used without compression or repainting. Their lossless
data-URL payloads allow offline local-file previews. The foreground textures are
oversampled relative to their displayed size and rendered at up to 2x pixel ratio.

The cutouts retain photographic lighting and volume while moving along the
existing curved 3D paths. They remain camera-facing rather than being stretched
into thin simulated side views. Globe occlusion still applies. This is a 2.5D
visual composition, not a full all-angle physical spacecraft simulation.

## Assets

- `sentinel-1-v1.png`: 1774 x 887, long SAR antenna and twin solar wings.
- `sentinel-2-v1.png`: 1536 x 1024, optical instrument and single solar wing.
- `change-v1.png`: 1774 x 887, Chang'e-inspired lunar orbiter.
- `tianwen-v1.png`: 1774 x 887, Tianwen-inspired Mars orbiter.

Decorative repeated spacecraft do not represent actual in-orbit quantities or
current mission positions. The scene uses three spacecraft around Terra, two
around Luna and two around Mars. The selected planetary background images remain
unchanged. The public site uses these assets for decorative orbital motion.
