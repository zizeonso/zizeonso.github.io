# Academic Homepage

A minimal PhD-style personal website for GitHub Pages.

## Edit

- `index.html`: all page content, links, publications, projects, and contact details.
- `assets/css/site.css`: colors, layout, responsive styles, and dark mode.
- `assets/img/avatar.svg`: replace with your profile photo.
- `assets/img/institution.svg`: replace with your school or lab logo.
- `assets/cv/cv.pdf`: optional CV file.

## Publish on GitHub Pages

1. Push this folder to a repository.
2. Open repository `Settings` > `Pages`.
3. Choose `Deploy from a branch`.
4. Select `main` and `/ (root)`.
5. Save.

The site has no build step. GitHub Pages can serve it directly.
